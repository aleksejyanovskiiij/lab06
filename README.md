# Лабораторная работа №6. Лемматизация и векторизация текстов

## Проделанные работы

В рамках работы выполнен разведочный анализ корпуса из 25 отзывов о фильмах (`reviews.csv`). Проведена очистка текстов (удаление ссылок, HTML-тегов, хэштегов, цифр и пунктуации, приведение к нижнему регистру) и лемматизация с помощью `pymorphy3`. Построены матрицы мешок слов и N-грамм (`CountVectorizer`), TF-IDF-матрица (`TfidfVectorizer`) с выделением ключевых слов по каждому документу. Выполнен разведочный анализ: топ-15 слов по частоте, распределение длин документов, косинусное сходство. В качестве бонусного задания построена PCA-визуализация документов с окраской по рейтингу.

## Процесс запуска

1. Создать и активировать виртуальное окружение:
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```
2. Установить зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Открыть ноутбук:
   ```bash
   jupyter notebook notebook.ipynb
   ```
   Все ячейки выполняются сверху вниз без ошибок.
